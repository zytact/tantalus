# Design

## Visual world

Codex Usage is an Operate surface modeled after a compact instrument panel. It uses a warm paper base, graphite type, an electric blue for active controls, and a restrained amber/red status vocabulary. The window is a single continuous working surface, not a grid of generic cards.

## Layout

The header states the current condition and contains the manual refresh. Two usage rows form the core, each with an explicit, server-confirmed duration, percentage, reset time, and a linear meter. An unknown duration becomes an unavailable row instead of being guessed. Credit expiry appears as a concise inventory beneath them. A narrow footer reports when the last successful data arrived and whether it is stale.

## Type and interaction

System sans-serif supports familiar desktop scanning. Numeric readings use tabular figures without switching to a fake terminal face. Controls use standard button behavior, clear focus outlines, and a short state transition. Color is never the only status signal.
