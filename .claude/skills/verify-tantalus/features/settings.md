# Settings

Settings contains, in order, provider switches for direct Codex, Claude, and Opencode, on Windows only the Windows and WSL sign-in switches (see `sign-in-sources.md`), Proxy hubs, Dragon and tortoise with its conditional details and Reset learning, Start 5-hour windows with Claude and Codex rows while enabled, Wake Claude sign-in with a Beta label, Usage in tray with its account picker while enabled, Open at login, Follow another Tantalus with its Connect button (see `host-link.md`), Local network, Tailscale, Paired devices, and the build version with Check for updates and the icon credit. The wake row remains visible when window starts are off. Back returns to the existing allowance snapshot.

Open at login registers a login item on macOS and Windows, and an XDG autostart entry on Linux. Login launches stay in the tray through `--hidden`, or the operating system's login-launch flag on macOS. It reads the operating-system state on each Settings mount, shows Checking or Saving during work, and keeps the old value on failure. The version comes from `package.json`. The adjacent update action has its own busy and error states. The remote access switches and paired devices, proxy hubs, window start and sign-in wake, tray usage, and dragon and tortoise rows are described in their own features.
